經濟學專題研究 / 計量模型架構 生成式 AI 浪潮對新台幣實質有效匯率（REER）與出口競爭力的非線性影響 本研究旨在探討生成式 AI 浪潮如何透過技術生產力躍升與非價格競爭力強化，對新台幣實質有效匯率與台灣出口競爭力產生非線性的動態傳導影響。 1. 研究假說 (Hypothesis) 與經濟學理傳導機制 假說 H1 生產力躍升與巴拉薩-薩繆爾森效應 生成式 AI 浪潮大幅提升台灣高科技產業（特別是半導體與 AI 供應鏈）的全要素生產力（TFP），引發非貿易品價格相對上升，推升新台幣實質有效匯率（REER）。 假說 H2 非線性門檻效應 生成式 AI 對出口競爭力的影響存在非線性門檻（Threshold Effect）。在 AI 資本存量或研發投入低於某一臨界門檻前，REER 升值對出口競爭力產生傳統的抑制效果；一旦跨越門檻，AI 帶來的高附加價值與品質彈性將削弱價格競爭力的劣勢，使 REER 升值的負面影響顯著降低或轉正。 經濟學理傳導圖解 ┌──────────────────────────────────────┐ │ 生成式 AI 浪潮 (軟硬體資本投入) │ └──────────────────┬───────────────────┘ │ Sector）生產力飆升。貿易品部門工資上漲帶動非貿易品部門（服務業）工資與價格跟漲，導致國內整體物價水準相對外國上升，推升新台幣實質有效匯率（REER 升值）。 價格彈性與非價格競爭力轉換（Non-Price Competitiveness） 傳統經濟學中，REER 升值代表出口產品相對變貴、競爭力下降。但在生成式 AI 驅動下，台灣出口結構向高技術密度產品傾斜，產品需求價格彈性顯著下降。企業藉由 AI 賦能提高產品附加價值，使出口競爭力從「價格競爭」轉為「技術與服務品質競爭」，抵銷了 REER 升值的不利影響。 2. 數據視覺化圖表建議 為精準捕捉非線性關係與時間動態，建議採用以下四類圖表： 圖表類型 建議分析應用 視覺化重點 雙 Y 軸時間序列圖 (Dual-Y Axis Line Chart) 觀察生成式 Python 資料清洗與計量分析程式碼 包含 AREMOS CSV 清洗、門檻交互項 OLS 與 VAR 時間序列模型分析 analysis_pipeline.py Python 3.x import numpy as np import pandas as pd import statsmodels.api as sm import statsmodels.formula.api as smf from statsmodels.tsa.api import VAR # ---------------------------------------------------- # 1. 資料清洗 (Data Cleaning) # ---------------------------------------------------- def clean_aremos_data(filepath): """清理 AREMOS 匯出的 CSV 資料檔格式""" # 讀取 CSV（假設 AREMOS 匯出檔前兩行為欄位名稱與註解，依實際情況調整） df = pd.read_csv(filepath, encoding='utf-8') # 清理欄位名稱空白 df.columns = df.columns.str.strip() # 建立時間索引 (假設時間欄位名為 'DATE'，格式如 '2020M01' 或 '2020Q1') if 'DATE' in df.columns: df['DATE'] = pd.to_datetime(df['DATE']) df.set_index('DATE', inplace=True) # 將數值欄位轉為 float，處理缺失值或 AREMOS 的特殊符號 (如 'M', '.') for col in df.columns: df[col] = pd.to_numeric(df[col].astype(str).str.replace(',', ''), errors='coerce') # 前向填補與後向填補缺失值 df = df.ffill().bfill() return df # 模擬建立範例資料（若使用實際 AREMOS 資料請調用 clean_aremos_data） np.random.seed(42) n_obs = 120 # 10年月資料 dates = pd.date_range(start='2015-01-01', periods=n_obs, freq='ME') # 模擬變數: 出口成長率 (EX), REER, AI變數 (AI_index) reer = 100 + np.cumsum(np.random.normal(0, 1, n_obs)) ai_index = np.where(np.arange(n_obs) < 95, np.random.normal(20, 2, n_obs), np.random.normal(20, 2, n_obs) + np.exp(np.linspace(0, 2.5, 25))) # 2022底後爆發 exports = 50 + 0.3 * ai_index - 0.2 * reer + (ai_index > 25) * (0.4 * reer) + np.random.normal(0, 3, n_obs) df = pd.DataFrame({'EXPORTS': exports, 'REER': reer, 'AI_INDEX': ai_index}, index=dates) # 取對數差異（計算對數成長率） df['ln_EXPORTS'] = np.log(df['EXPORTS']) df['ln_REER'] = np.log(df['REER']) df['d_ln_EXPORTS'] = df['ln_EXPORTS'].diff() df['d_ln_REER'] = df['ln_REER'].diff() df_clean = df.dropna() # ---------------------------------------------------- # 2. 非線性迴歸分析 (Nonlinear / Interactive Regression) # ---------------------------------------------------- # 建立 AI 指標的門檻虛擬變數 (Threshold Dummy) threshold_val = df_clean['AI_INDEX'].quantile(0.75) # 以75百分位數為門檻範例 df_clean['High_AI'] = (df_clean['AI_INDEX'] > threshold_val).astype(int) # 模型 A: 包含交叉項的非線性線性迴歸 (Interaction Model) # d_ln_EXPORTS = β0 + β1*d_ln_REER + β2*High_AI + β3*(d_ln_REER * High_AI) model_inter = smf.ols('d_ln_EXPORTS ~ d_ln_REER * High_AI + AI_INDEX', data=df_clean).fit() print("=== 1. 門檻交互作用 OLS 迴歸結果 ===") print(model_inter.summary()) # ---------------------------------------------------- # 3. 時間序列分析 (VAR 模型與脈衝響應) # ---------------------------------------------------- var_data = df_clean[['d_ln_EXPORTS', 'd_ln_REER', 'AI_INDEX']] var_model = VAR(var_data) var_results = var_model.fit(maxlags=4, ic='aic') print("\n=== 2. VAR 模型估計結果摘要 ===") print(f"選用最佳滯後期數 (Lag): {var_results.k_ar}") # 計算脈衝響應分析 (IRF) irf = var_results.irf(periods=10) # irf.plot(orthogonalized=True) # 可直接繪圖 © 研究計畫專題報告 - 生成式 AI 與匯率經濟學分析
