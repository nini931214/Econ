生成式 AI 浪潮對新台幣實質有效匯率（REER）與出口競爭力的非線性影響

探討 AI 技術創新引發的生產力躍升與非價格競爭力轉型，如何重新定義匯率對台灣出口效應的傳導機制。

Section 01

研究假說與傳導機制

Hypothesis 01

生產力躍升與巴拉薩-薩繆爾森效應

生成式 AI 浪潮大幅提升台灣高科技產業（特別是半導體與 AI 供應鏈）的全要素生產力（TFP），引發非貿易品價格相對上升，推升新台幣實質有效匯率（REER）。

Hypothesis 02

非線性門檻效應

在 AI 資本存量低於臨界門檻前，REER 升值對出口產生傳統抑制效果；一旦跨越門檻，AI 帶來的高附加價值將削弱價格劣勢，使升值的負面影響顯著降低甚至轉正。

經濟學理傳導架構

生成式 AI 浪潮 (軟硬體資本投入)
管道 A：價格與匯率管道

科技產業 TFP 躍升

帶動貿易品部門生產力飆升與工資上漲，引發服務業等非貿易品價格上升（巴拉薩-薩繆爾森效應）。

新台幣 REER 實質升值
管道 B：結構與品質管道

非價格競爭力強化

出口結構轉向高技術密度產品，需求價格彈性下降，競爭力改由技術與服務品質驅動。

產品附加價值與不可替代性提升
最終綜合影響
對衝 REER 升值之價格劣勢 ➔ 保障並提升出口總量與市佔率

import numpy as np
import pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf
from statsmodels.tsa.api import VAR

# ----------------------------------------------------
# 1. 資料清洗 (Data Cleaning)
# ----------------------------------------------------
def clean_aremos_data(filepath):
    """清理 AREMOS 匯出的 CSV 資料檔格式"""
    df = pd.read_csv(filepath, encoding='utf-8')
    df.columns = df.columns.str.strip()
    
    if 'DATE' in df.columns:
        df['DATE'] = pd.to_datetime(df['DATE'])
        df.set_index('DATE', inplace=True)
    
    for col in df.columns:
        df[col] = pd.to_numeric(df[col].astype(str).str.replace(',', ''), errors='coerce')
        
    return df.ffill().bfill()

# 模擬數據建立 (10 年月資料)
np.random.seed(42)
n_obs = 120
dates = pd.date_range(start='2015-01-01', periods=n_obs, freq='ME')

reer = 100 + np.cumsum(np.random.normal(0, 1, n_obs))
ai_index = np.where(np.arange(n_obs) < 95, 
                    np.random.normal(20, 2, n_obs), 
                    np.random.normal(20, 2, n_obs) + np.exp(np.linspace(0, 2.5, 25)))
exports = 50 + 0.3 * ai_index - 0.2 * reer + (ai_index > 25) * (0.4 * reer) + np.random.normal(0, 3, n_obs)

df = pd.DataFrame({'EXPORTS': exports, 'REER': reer, 'AI_INDEX': ai_index}, index=dates)

# 計算對數成長率 (Log Difference)
df['d_ln_EXPORTS'] = np.log(df['EXPORTS']).diff()
df['d_ln_REER'] = np.log(df['REER']).diff()
df_clean = df.dropna()

# ----------------------------------------------------
# 2. 非線性迴歸分析 (Nonlinear Regression)
# ----------------------------------------------------
# 設立門檻變數 (Threshold Dummy)
threshold_val = df_clean['AI_INDEX'].quantile(0.75)
df_clean['High_AI'] = (df_clean['AI_INDEX'] > threshold_val).astype(int)

# 估計門檻交互作用模型
model_inter = smf.ols('d_ln_EXPORTS ~ d_ln_REER * High_AI + AI_INDEX', data=df_clean).fit()
print("=== 門檻交互作用 OLS 迴歸結果 ===")
print(model_inter.summary())

# ----------------------------------------------------
# 3. 時間序列分析 (VAR 模型)
# ----------------------------------------------------
var_data = df_clean[['d_ln_EXPORTS', 'd_ln_REER', 'AI_INDEX']]
var_results = VAR(var_data).fit(maxlags=4, ic='aic')

# 計算脈衝響應分析 (IRF)
irf = var_results.irf(periods=10)
# irf.plot(orthogonalized=True)
